R-OS RUN Exchange

Особистий локальний інструмент для обміну пакетами обробки відео між R-OS Local Execution System та Google Drive.

Ланчер створює RUN-папки, завантажує текст транскрипції, часові сегменти й маніфест, створює заготовки результатів та перевіряє контрольні суми. Оригінальне відео у цьому RUN Exchange залишається на комп’ютері.

Доступ Google OAuth обмежений drive.file: файли, створені застосунком або явно вибрані власником. Для роботи з ChatGPT власник окремо використовує його Google Drive connector.

Інструмент призначений для особистого використання власником облікового запису. Контакт: rostyslav.diakun@gmail.com.
